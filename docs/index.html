Netflix Pro

Your seamless gateway to movies and TV shows, right on your mobile device.

Android release Source on GitHub

Overview

Netflix Pro browses movies and TV shows using TMDB for metadata and resolves playback through its own Net-web gateway, which returns playable sources with the headers each provider requires. The app is personal-use software, distributed only as a source build.

Personal use only. This is a private project, not a published product. It is not distributed through any app store, and it is not licensed for redistribution or commercial use.

Features âœ¨

  • Cross-Platform: Runs on both iOS and Android.
  • Rich Metadata: Detailed info from TMDB.
  • Playback: Adaptive quality and audio-track selection from the player's own tracks.
  • Downloads: Choose a quality and save for offline playback.
  • Subtitles: Search, import, style and sync-offset controls.
  • Locale-aware: Interface and catalogue follow your language and region.
  • Skip intro & credits: Recognised from the title itself, not a fixed timestamp.
  • Watch Progress: Saves your last watched position.
  • Auto-Play Next: Automatically plays the next episode.
  • Client-Side: No server needed.
  • Clean UI: User-friendly design.
